# AUDIT — реальные NPC, диалоги и звуки HUB (develop)
> Документ получен из **фактических** данных Unity на ветке `develop`; не фантазия о наличии новых NPC. Исходная выборка: `Assets/Resources/HubAudio/NpcDialogues.json`.

## Фактический состав
- Всего **62 записей** в `NpcDialogues.json`: **49** обычных жителей, **12** персонажей кабаре, **1** придворный музыкант.
- В каждой записи сейчас по **3** страницы текста, всего 186 страниц. Имена и первые строки приведены ниже; полный текст остаётся в оригинальном JSON.
- **Отдельно** имеются **3 `RoyalMarketVendor`** со своими диалогами и магазином: Грегор «Два Ценника», Марта «Семь Узлов», Бруно «Тихая Сделка». Это **не записи** данного JSON.
- Отдельно есть визуальный король `King - authored seated visual only`. В проверенном установщике NPC ему **не** назначается обычный `HubNpcDialogueInteractable`. Не считать его 66-м интерактивным диалогом.
- У большей части 62 персонажей реплики бытовые. Наличие NPC ≠ важный сюжетный персонаж. В тексте нет прямой разгадки королевской программы.

## Как это реально работает
1. `HubNpcLivingSetup.Ensure` собирает активных горожан под сценовым корнем `[ART] HUB inhabited districts - curated redo`, актёров `CabaretActor` и придворного музыканта; для NPC находит карточку **по полному пути объекта в сцене** через `HubNpcDialogueCatalog.TryGet(PathOf(...))`. При перемещении/переименовании корней существует риск потерять разговоры. **Не переименовывать сценовые пути просто ради сюжета.**
2. `HubNpcDialogueInteractable`: `E — Поговорить: <имя>`, только живой игрок, без активного удерживаемого предмета и других блокирующих действий.
3. `HubNpcDialogueHud`: **локальный HUD слушателя**, три страницы, Enter/пробел/кнопка — дальше, Escape — закрыть; текст можно прокручивать. На каждой новой странице NPC проигрывает короткий 3D звук реакции через Dialogue bus, не озвученный текст.
4. `HubNpcDialogueInteractable.PlayDialogueVoice`: обычный набор коротких звуков из `Resources/Market/Audio`; для female используется `HubAudio/NpcVoices` (Murmur/Sigh/Laugh). Быстрый Next не накладывает старые фразы друг на друга.
5. `HubNpcAmbientEnvironment` воспроизводит небольшое количество фоновых локальных голосов (пул до 2–3 одновременно, а не 62 звучащих 3D-источника); во время разговора с конкретным NPC его ambient-болтовня подавляется.
6. `HubAudioEnvironment.SetDialogueActive` приглушает HUB музыку и фон во время текста; `HubUiClickAudio.SetDialogueAudio` не даёт универсальным hover/click мешать речевым реакциям.
7. `CabaretInformationPoint` передаёт взаимодействие на имеющийся диалог; ни разрушаемость, ни коллайдеры, ни анимации кабаре менять не нужно.
8. `RoyalMarketVendor` + `MarketPlayerUI` — **другая UI система**, со вступлением, рангами и ассортиментом. Грегор использует четыре `Gregor_Dialogue_0*.mp3` как короткие звуки; Марта/Бруно наследуют похожий mumble-пул. При развитии сюжета не переводить торговцев в общий HUD.
9. `HolyShipBoardAudio` использует специальные звуки бумаги/дерева. Оставить стилистику Mission Board и его UI исключения.

## Для сценария: что делать, чего не делать
**Делать:**
- сохранить весь этот список NPC и уже существующие строки, а сюжетные слухи добавлять отдельным условным слоем (storyBeat/репутация/островные milestone);
- поначалу выбрать 6–10 **дополнительных** событий-реплик суммарно для: Собирателя новостей, Соседа с новостями, Счётчика на складе, Торы, Борена, Гаррета, Вилолы, Грегора/Марты/Бруно, Рыбака, музыканта;
- обеспечивать fallback на нынешние три страницы; запрещено удалять их при прогрессе и делать диалог обязательным квестовым блокером;
- применять сюжетные ветви через **стабильный NPC ID** при расширении системы, оставляя текущую path-keyed загрузку для существующего массива, а не через сравнение отображаемых имён.

**Не делать:**
- покупать профессиональные голоса для 62 NPC, торговцев или для каждого текстового слова;
- наслаивать звуки generic UI поверх текущих dialogue мumbles;
- заменять весь диалог иHUD новым интерфейсом, автоматически менять имена/пути в Unity сцене, включать глобальную voice-chat озвучку;
- принуждать игроков разговаривать со всеми горожанами до первого плавания.
