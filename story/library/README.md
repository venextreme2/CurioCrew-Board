# Holy Ship! — Narrative / Сценарная документация

**Редакция:** 0.1, 08.10.2026. **Статус:** рабочий сценарный канон (proposal), не реализованный контент. **База исследования:** `develop` коммит `fd1aeca2baee2e073a004cbd1ad41cf9447f5c28`.

## Что утверждено направлением проекта
- Holy Ship! — кооператив 1–4, физические экспедиции, абсурдные ситуации и загадка большого мира; не чистый хоррор, не традиционная RPG.
- **Полный релиз = 20 островов, 4 главы по 5 островов**. Alpha = только глава I, острова 1–5. Пятый остров не раскрывает главную тайну и не заканчивает основную историю.
- Кат-сцен с **записанной человеческой речью ровно пять по базовому плану**: вступление (C0) и четыре окончания глав (C1/C2/C3/C4). В обычных разговорах NPC — **текст + текущие короткие звуки-междометия**, без озвучки каждой реплики.
- Первые два острова — плотные, многомаршрутные, тщательно проработанные территории. 3–5 острова могут быть специализированными миссиями со своим геймплеем; не делать 20 одинаковых открытых карт.
- HUD диалогов NPC, торговые интерфейсы, звуки, NPC ambience, особый звук бумаги у доски миссий и FishNet **не изменять в рамках сценарной работы**.

## Степень определённости
- **Фиксируем по согласованной постановке:** 20 островов / четыре главы, альфа = 1–5, пять озвучиваемых кат-сцен, сохранение звуковых реакций NPC.
- **Рабочая концепция для сценария:** Великий Фарватер, 20 узлов, история древней системы, мотивы короля, исчезнувшая экспедиция, два этических исхода — требуют согласования перед реализацией или рекламными текстами.
- **Конкретные идеи, НЕ закреплённый production scope:** остров 3 — доставка тележки, остров 4 — длинная река с плаванием, остров 5 — ориентирование по звуку в манграх. Их можно заменить без переписывания мирового канона.
- Имена новых персонажей, имена реликвий и названия древней цивилизации не считать существующими ассетами/локализацией.
- Не создавать автоматически новые NPC/режимы, не обещать готовую кат-сцену: документы — сценарий и технический контракт.
