# Holy Ship! Board

Внутренний сайт проекта Holy Ship!

Разделы:
- Разработка — общий трекер задач
- Артефакты
- Королевские артефакты
- Острова
- Мобы
- Сюжет — коротко для команды + сценарная библиотека и контекст для Codex
- Дневник разработки

Supabase подключён. Задачи хранятся в `tasks`, игровая база — в `game_content`.
Изменения синхронизируются между открытыми страницами в реальном времени.

Во всех редактируемых разделах доступны изображения (в том числе drag & drop) и отдельное поле `Промт для Codex`.

Сайт остаётся статическим и подходит для GitHub Pages.

## Сюжет и сценарная библиотека

- `story.html` — страница «Сюжет» с двумя режимами: краткое объяснение для двух разработчиков и подробная библиотека с поиском и просмотром Markdown прямо на сайте.
- `story/library/*.md` — девять полных сценарных документов (канон мира, 20 островов, альфа 1–5, NPC, кат-сцены C0–C4, технические правила), опубликованных снимком v0.1 от 08.10.2026.
- Кнопки «Контекст Codex» и «Вся библиотека» копируют инструкции/исходники, но сами ничего не меняют в игровом репозитории.
- Источник редакции — закрытая разработческая ветка игрового репозитория `venextreme2/Curio-Crew:narrative/story-bible-alpha-20261008` (`Documentation/Narrative`). Обновления в игровом репозитории **не подтягиваются автоматически** на сайт и наоборот.
- **Важно:** GitHub Pages публичный. Подробный раздел содержит сюжетные спойлеры до финала; раздел не ограничен аутентификацией. Если сюжет нужно скрыть от игроков, необходима приватная библиотека/доступ.

Этот релиз не затрагивает Supabase-таблицы, игровой код или диалоги NPC.
