# CurioCrew Simple Board

Supabase уже подключён.

Открой `index.html` — сайт должен показать:
`Общий режим • синхронизация включена`.

Данные хранятся в общем Supabase-проекте.
Изменения задач синхронизируются между открытыми страницами в реальном времени.

Для общей ссылки достаточно выложить 4 файла (`index.html`, `styles.css`, `app.js`, `config.js`)
на любой статический хостинг, например GitHub Pages.
